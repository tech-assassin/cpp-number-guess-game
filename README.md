
# 🎯 C++ Number Guessing Game

A simple command-line game where the user tries to guess a random number between 1 and 100.

## 🧠 How It Works
- Generates a random number
- Prompts user input
- Gives hints: `Too high` / `Too low`
- Ends when the correct number is guessed

## 🚀 Built With
- C++
- g++ (MinGW)
- Visual Studio Code

## 📦 How to Run
1. Compile:
   ```bash
   g++ number_guess.cpp -o number_guess.exe
